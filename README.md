# Tehnologii-Web-2025-2026
Cursuri, laboratoare, teme și readme pentru Tehnologii web an 2 sem 2 (2025-2026). 
1. Ce este o resura (resource) in aplicatia ta?
   R: O resursa din aplicatia mea este "Acasa". O resursa este un obiect de interes pe care aplicatia mea il gestioneaza si care poate fi accesat printr-un link.
2. Da exemplu de un URI si explica componentele acestuia.
   R: URI - uniform resource identifier. Este un sir de caractere folosit pentru a identifica in mod unic o resursa.
   Ex: http://127.0.0.1:5500/Tehnologii%20WEB/Laboratoare/Lab%202/index.html
   http - scheme(protocol): conexiune standard, nesecurizata, folosita de obicei in dezvoltarea locala.
   127.0.0.1 - authority(ip host): adresa de "localhost"
   :500 - deschisa de Liver Server pentru a livra fisierele
   /Tehnologii%20WEB/Laboratoare/Lab%202/ - path(cale) -
   index.html - resource(resursa finala) -fisierul specific cerut de la server-ul local.
3. Care parti sunt statice si care sunt dinamice?
   R: Partile statice - resurse nu se schimba indiferent de cine le priveste: HTML, CSS, etc.
   Partile dinamice - generate "la cerere": codul javaScript, rezultatele filtraii evenimentelor.
4. Este aplicatia ta document-centric sau interactive (sau ambele)? De ce?
   R: Aplicatia este una hibrida, dar inclina spre a fi o aplicatie web interactiva.
